# 甘特图（Gantt）

任务/阶段在时间轴上的排期。

## 布局语法

- 左侧任务列（sans 12px，宽 160-200px），右侧时间轴
- 时间刻度在顶部：mono 8px，竖直细分隔线（rule 色）贯穿全图
- 任务条：高 16px，rx=4；常规条 ink 80% 填充，**关键路径**用 accent 填充（≤2 条）
- 阶段分组：同阶段任务条上方加 8px 高 muted 20% 的通栏底带 + mono 8px 阶段名
- 里程碑：菱形 accent 描边小标记 + 右侧标注
- 今日线：link 色竖虚线 `4,3` + 顶部「今日」小标
- 依赖：从前置任务条右端到后续任务条左端的细肘形线（r=6，muted）

## 画法

```svg
<rect x="300" y="120" width="240" height="16" rx="4" fill="#1f2937" opacity="0.8"/>
<text x="292" y="132" text-anchor="end" font-size="12" fill="#1f2937">需求评审</text>
```

条上可写百分比（白字 8px，完成度）；未开始的条用 ink 20% 描边虚线 + 无填充表示计划。

## 预算

任务 ≤12、阶段 ≤5、里程碑 ≤3、依赖线 ≤6。

## 反模式

- 时间刻度不等距（周末压缩会造成误读，保持匀速）
- 任务条高度不一
- 每个任务都标依赖（只画关键依赖）
