# 柱状图（Bar Chart）

跨类别的数值比较。**手写 SVG，数值换算必须严格按本文公式，禁止目测。**

## 画布分区（定死）

以 `viewBox="0 0 1000 600"` 为例：

```
左边距 64（Y 轴标签）  右边距 32
上边距 32              下边距 48（X 轴标签）
绘图区 = x:[64, 968], y:[32, 552]，plotH = 520
```

## 数值 → 像素换算（公式）

1. **niceMax**：把数据最大值向上取"好看数"——从 {1, 1.2, 1.5, 2, 2.5, 3, 4, 5, 6, 8} × 10^n 中选最小能覆盖 max 的
2. **刻度**：Y 轴取 4-5 格，步长 = niceMax / 4 或 / 5
3. 基线 `baseY = 552`，柱高 `barH = round(value / niceMax × plotH)`，柱顶 `y = baseY - barH`
4. 柱宽：类目数 N 时，类目带宽 `band = plotW / N`，柱宽 = band × 0.56（取 4 的倍数），居中放置
5. 多系列：类目内并排，单柱宽 = band × 0.8 / 系列数，系列间距 4px

## 元素规范

- Y 轴线 + X 轴线：ink 60%，1px；网格线：横向虚线 `4,4`，rule 色，只画横向
- Y 刻度标签：mono 8px，右对齐于 x=56；X 类目标签：sans 12px，居中于柱中点下方 16px
- 数值标签：mono 8px 放柱顶上方 8px（单系列时直接标，省掉图例）
- 系列配色顺序：`ink` → `muted` → `link` → `soft`；**高亮系列/单柱**用 `accent`（≤2）
- 图例：仅多系列时需要，底部横条（通用规则）

## 画法

```svg
<line x1="64" y1="32" x2="64" y2="552" stroke="#23272e" opacity="0.6"/>
<line x1="64" y1="552" x2="968" y2="552" stroke="#23272e" opacity="0.6"/>
<line x1="64" y1="162" x2="968" y2="162" stroke="rgba(35,39,46,0.12)" stroke-dasharray="4,4" stroke-width="0.8"/>
<rect x="160" y="292" width="64" height="260" rx="4" fill="#23272e"/>
<text x="192" y="284" text-anchor="middle" font-size="8" font-family="ui-monospace,Menlo,monospace" fill="#5c6470">32.5</text>
<text x="192" y="572" text-anchor="middle" font-size="12" fill="#23272e">杭州</text>
```

## 预算

柱 ≤8（单系列）/ 类目 ≤6 × 系列 ≤3；Y 刻度 4-5 格。

## 反模式

- 基线不从 0 开始（必须 0 基线，否则视觉误导；数据差异小时用折线图而非截断柱状图）
- 3D/渐变/圆角 >4px
- 每根柱不同色（单系列单色，高亮才用 accent）

> **网格豁免**：由公式换算出的数据几何（柱高、折点坐标、切片角度）优先服从数值准确性，**不强制 4 的倍数**；坐标轴/边距/标签等布局框架仍守 4px 网格。self_check 的网格警告对数据元素可忽略。
