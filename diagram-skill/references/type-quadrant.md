# 象限图（Quadrant）

双轴定位 / 优先级评估（如 重要-紧急、价值-成本）。

## 布局语法

- 白底大正方形区域，十字轴线（ink 60%，1px）分四象限；轴**两端带箭头**表示方向
- 轴标签：两端各一个（mono 8px 大写或中文 ≤4 字，muted），如「低成本 → 高成本」
- 象限名：每象限角落 mono 8px muted 标签（如「优先做」「暂缓」）
- 条目 = 8px 圆点 + 右侧 sans 12px 标签；焦点条目（1-2 个）用 accent 圆点 + 加粗标签
- 条目定位即内容：x/y 坐标体现两个维度的评估，不要均匀撒点（那是散点图）

## 预算

条目 ≤12、焦点 ≤2、象限名 ≤4 字。

## 反模式

- 条目落在轴线上（评估不清就重新评估，别骑线）
- 标签压点（标签在点右侧 8px 起）
- 轴没有方向箭头/端点标签（读者不知道哪头是好）
