# 流程图（Flowchart）

带分支的决策逻辑。

## 布局语法

- 主流向**上→下**；分支走向右，汇合回到主干
- 形状语义（全图统一）：
  - 起止：圆角最大（rx=16）的胶囊，ink 填充白字
  - 步骤：白底 rx=6 方框（常规节点）
  - 判断：菱形（`<polygon>`），accent-tint 填充 + accent 描边；全图焦点色尽量只给菱形
- 分支标注：菱形的出线上标注「是/否」或条件，mono 8px + 遮罩，遵守 6-10px 间隙规则
- 汇合：分支回到主干用一条水平归拢线，不要每条分支各自连到下一步

## 菱形画法

```svg
<polygon points="cx,cy-28 cx+56,cy cx,cy+28 cx-56,cy"
         fill="rgba(194,69,30,0.08)" stroke="#c2451e" stroke-width="1"/>
<text x="cx" y="cy+4" text-anchor="middle" font-size="12" font-weight="600" fill="#23272e">条件?</text>
```

（菱形内文字 ≤8 个汉字；放不下就缩短条件，细节写到正文）

## 预算

节点 ≤9（菱形计入）、分支 ≤2 层嵌套、连线 ≤12。

## 反模式

- 菱形里塞长句子
- 分支交叉穿越（重排让「否」统一走一侧）
- 起止节点多于 2 个（合并入口）
