# 架构图（Architecture）

系统组件 + 连接关系。最常用的类型。

## 布局语法

- **分区（zone）优先**：相关组件用虚线圆角大框分组（`stroke: ink 30%`，虚线 `6,4`，填充 `ink 3%`），区名用 mono 8px 大写放左上角
- 流向默认**左→右**或**上→下**，全图只选一个主方向
- 外部系统/用户放最左或最上，数据存储放最右或最下
- 节点内：mono 8px 类型标签（API/DB/UI，矩形小框 rx=2）+ sans 12px 节点名 + mono 9px 技术子标签（`host:port`）

## 肘形连线公式（正交圆角，必用）

从 A 右缘 (x1,y) 到 B 左缘 (x2,y)，中点 mx=(x1+x2)/2：

```svg
<path d="M x1,y L mx-8,y Q mx,y mx,y-8 L mx,by+8 Q mx,by mx+8,by L x2,by"
      fill="none" stroke="#5b6b80" stroke-width="1.2" marker-end="url(#arrow)"/>
```

（方向按实际象限调整正负号；r=8 是四分之一圆弧半径）

## 交叉线（桥跳 primitive）

两线必须交叉时，上层线在交叉点断开一个小弧：

```svg
<path d="M x-8,y A 8,8 0 0 1 x+8,y" .../>  <!-- 凸起的桥 -->
```

## 预算

节点 ≤9、连线 ≤12、分区 ≤3、焦点 ≤2。

## 反模式

- 所有节点同款白框（用填充/描边区分类型：见 SKILL.md §3 节点处理表）
- 箭头双向滥用（单向能说清就不用双头）
- 把每个组件都标成焦点色
