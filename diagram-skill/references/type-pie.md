# 饼图 / 环形图（Pie / Donut）

部分与整体。**优先画环形（Donut）**：中心可放总计数，标签更好排。**角度计算按公式来。**

## 角度 → 坐标换算（公式，逐步照做）

1. 每切片占比 `p = value / total`；角度 `sweep = p × 360`
2. 从 12 点方向（-90°）顺时针累计：`a_start = -90 + 累计角度`，`a_end = a_start + sweep`
3. 角度 a（度）转坐标（圆心 cx,cy，外半径 r）：
   ```
   x = cx + r × sin(a × π/180)
   y = cy - r × cos(a × π/180)
   ```
4. 环形切片路径（外半径 rO=120，内半径 rI=64）：
   ```svg
   <path d="M x1o,y1o A rO,rO 0 L,1 x2o,y2o L x2i,y2i A rI,rI 0 L,0 x1i,y1i Z"/>
   ```
   其中 L（largeArc）= sweep > 180 时取 1 否则 0；下标 o/i = 外圈/内圈坐标
5. **先心算或草稿列出每片的 a_start/a_end/四角坐标，核对累计 = 360°，再写 SVG**

## 元素规范

- 圆心放绘图区中心偏左（如 cx=320, cy=300），右侧留给标签列表
- 配色顺序：`ink` → `muted` → `link` → `soft` → `ink 40%`；最大切片或用户关注点可用 `accent`（≤1-2）
- 标签：右侧竖排列表——8px 色块圆点 + sans 12px 名称 + mono 8px 百分比（`p×100` 保留 1 位小数）
- 环形中心：总计数（serif 24px）+ 说明（mono 8px muted）
- 切片间 2px 纸色描边分隔（`stroke="#ffffff"` stroke-width=2）

## 预算

切片 ≤6，超出合并为「其他」；标签全部右排，**禁止引线标注**。

## 反模式

- 3D 饼图、爆炸切片
- 切片多于 6 个（合并成"其他"）
- 角度凭感觉估算（必须按公式算；算错整个图失真）
- 标签围着圆周放射排布（中文易截断，右侧列表才是正解）

> **网格豁免**：由公式换算出的数据几何（柱高、折点坐标、切片角度）优先服从数值准确性，**不强制 4 的倍数**；坐标轴/边距/标签等布局框架仍守 4px 网格。self_check 的网格警告对数据元素可忽略。
