# 状态机（State Machine）

状态 + 迁移 + 触发条件。

## 布局语法

- 状态 = 圆角胶囊（rx=16，白底 ink 描边，sans 12px）
- 初始：ink 实心小圆点 → 箭头指向初始状态；终止：双层圆环
- 当前/焦点状态：accent-tint + accent 描边（≤1-2 个）
- 迁移线：正交肘形或直线（共轴时），标注 = **事件 [条件] / 动作**，mono 8px + 遮罩 + 6-10px 间隙
- 自循环：状态框上方小 U 形回环
- 布局按"主流程"排成左→右主轴，异常/回退迁移走下方折返线，避免交叉

## 画法

```svg
<circle cx="60" cy="200" r="6" fill="#23272e"/>
<path d="M 66,200 L 96,200" stroke="#5c6470" marker-end="url(#arrow)"/>
<rect x="100" y="184" width="96" height="32" rx="16" fill="#fff" stroke="#23272e"/>
<text x="148" y="204" text-anchor="middle" font-size="12" fill="#23272e">待支付</text>
```

## 预算

状态 ≤8、迁移 ≤12、标注尽量 ≤6 字（「支付成功」而非「用户完成支付操作后」）。

## 反模式

- 所有状态一个色（区分正常态/异常态：异常态可用 muted 虚线描边）
- 迁移不标事件（裸箭头等于没画）
- 回退线穿图中央（统一走外围）
