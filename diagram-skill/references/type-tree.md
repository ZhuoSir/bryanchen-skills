# 树状图（Tree）

父子层级关系（组织架构外的通用层级：目录、分类、WBS 等）。

## 布局语法

- **左→右横排**（默认）：根在最左，逐层向右展开；层间距 180-240px
- 连接线：正交肘形（父右缘 → 子左缘），子节点在父的垂直覆盖范围内尽量均布
- 层级越深颜色越淡：L0 ink 描边白底 → L1 常规 → L2+ muted 描边；焦点路径用 accent
- 节点高 32-40px；同层节点垂直间距 ≥16px
- 可折叠/汇总的分支用「+N 项」灰框代替展开（预算控制手段）

## 预算

深度 ≤4、总节点 ≤12（含「+N」汇总框）、焦点路径 ≤1 条。

## 反模式

- 根节点放顶部做纵排（中文层级深时横向利用率更高；顶层 ≤3 层才考虑纵排）
- 子节点不对齐（同层左缘必须对齐同一 x）
- 每个叶子都画（超过预算就汇总成「+N 项」）
