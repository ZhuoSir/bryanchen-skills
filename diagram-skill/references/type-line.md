# 折线图（Line Chart）

连续趋势（时间序列为主）。**数值换算按公式，禁止目测。**

## 画布分区

同柱状图：`x:[64, 968]`, `y:[32, 552]`, plotH = 520，baseY = 552。

## 数值 → 像素换算（公式）

1. **Y 轴不必从 0 起**：`yMin = 向下取好看数(min)`，`yMax = 向上取好看数(max)`（好看数同柱状图规则），让曲线占满绘图区中段
2. `y = baseY - round((value - yMin) / (yMax - yMin) × plotH)`
3. X 轴：N 个数据点等距，`x_i = 64 + round(plotW × i / (N-1))`（首尾贴边）；时间标签只标 4-6 个关键刻度，其余省略
4. 折点：圆点 r=4，实底（系列色）+ 2px 纸色描边

## 元素规范

- 折线：2px 实线，系列色；`fill="none"`，用 `<polyline>` 或 `<path>`
- 网格线：只画横向虚线（rule 色）
- **直接标注代替图例**：单/双系列时把系列名写在曲线末端右侧（sans 12px 系列色）；3 条以上才用底部图例
- 关键点标注：峰值/谷值/拐点用 mono 8px 数值标签（点上/下方 10px），全图 ≤4 处
- 渐变面积填充（可选）：`fill` 系列色 8% 透明度，描边不变

## 画法

```svg
<polyline points="64,392 192,340 320,288 448,236 576,184 704,132 832,158 968,96"
          fill="none" stroke="#23272e" stroke-width="2"/>
<circle cx="832" cy="132" r="4" fill="#23272e" stroke="#f7f5f2" stroke-width="2"/>
<text x="832" y="116" text-anchor="middle" font-size="8" font-family="ui-monospace,Menlo,monospace" fill="#5c6470">33.7°</text>
<text x="968" y="120" text-anchor="end" font-size="12" fill="#23272e">杭州</text>  <!-- 末端直接标注 -->
```

## 预算

每系列点 ≤12、系列 ≤3、关键点标注 ≤4。

## 反模式

- 所有点都标数值（只标关键拐点）
- 系列都用同色加图例（直接标注优先）
- 平滑曲线（贝塞尔平滑会虚构数据，折线就老老实实直线连接）
- 双 Y 轴（另画一张图）

> **网格豁免**：由公式换算出的数据几何（柱高、折点坐标、切片角度）优先服从数值准确性，**不强制 4 的倍数**；坐标轴/边距/标签等布局框架仍守 4px 网格。self_check 的网格警告对数据元素可忽略。
