## 质量闸（比记更重要）
1. **防再犯规则写不出 = 不配进台账**（感慨不是坑，可检查的动作才是）
2. 祈使句 + 可检查：❌「注意镜像问题」 ✅「改 .env IMAGE_TAG 后必须 compose up -d 并核对运行中 tag」
3. 记前 grep `L-` 去重，同类加复发计数；复发 ×2 即防再犯规则失效，回炉重写该条
4. 与 standards 的关系：普适坑 → 升格为 standards/ 条款并记「退休(→条款号)」；项目特有坑保持 active
5. active 超 ~80 条触发季度审，休眠/退休移入文件尾「冷库」区（冷库条目不参与 Plan 核对）

## 用（消费端，闭环所在）
- **Plan 阶段强制核对全部 active 坑**（SKILL §3「坑核对」节，沉默=未核对，确认②不放行）
- 坑被核对过、方案仍踩 → 说明防再犯规则不可执行，回炉该 L 条
- M4 演练复盘、init 体检（旧坑迁移）都读写本表
- 坑导致的缺陷：BUG 行注 `L-xx`，双向可查
