# 12306 查询 Skill（12306-skill）

零依赖（Python 3 标准库）、免登录、免 Key，数据源为 12306 官网（kyfw.12306.cn）网页版前端自用的公开查询 JSON 接口。**只做查询，不做订票。**

## When to Use

✅ 用户说：查火车票 / 查余票 / "明天去北京还有票吗" / 高铁动车时刻 / "G103 几点到哪" / 经停站查询

❌ 不适用：订票、抢票、候补下单（无官方 API，登录+验证码+实名核验不可自动化，违反 12306 条款且有封号风险——一律告知用户去官方 App/网站操作）；机票、汽车票

## 执行流程

所有脚本位于本 skill 目录的 `scripts/` 下，用 bash 运行，JSON 输出到 stdout（`ok=false` 时读 `error` 字段）。

### 查询余票

```bash
python3 scripts/tickets.py --from 北京 --to 上海 --date 明天
python3 scripts/tickets.py --from 北京 --to 上海 --date 2026-08-25 --type G,D
python3 scripts/tickets.py --from 北京 --to 上海 --date 今天 --train G103
```

- `--date`：`YYYY-MM-DD` 或 `今天/明天/后天`（默认明天）
- `--type`：按车次类型过滤，逗号分隔（`G,D,C,K,T,Z,数字`）
- `--train`：只看指定车次
- 车站名可直接用中文（北京 / 北京南 均可，接口自动按实际到发站显示），也支持三字码
- 座位值含义：`有` = 充足，数字 = 剩余张数，`无` = 售罄，`候补` = 只能候补；输出中只保留有信息的座位项

### 查询时刻表（经停站）

```bash
python3 scripts/schedule.py --train G1 --from 北京南 --to 上海虹桥 --date 明天
```

- 12306 的时刻接口需要内部 train_no，脚本会先通过余票接口定位车次，**请尽量带上 `--from/--to` 区间**（该车次当日实际经过的区间）
- 不带区间时会自动尝试若干干线区间兜底；找不到时会明确报错（当日不开行或区间不对）
- 输出该车全程经停站：到达/出发时刻、停留分钟数

## 回答风格

- 余票结果**逐趟列表格**：车次 / 出发-到达 / 历时 / 各席别余票；二等座售罄但其他席别有票的要明确提示
- 用户问"还有票吗"时，先给结论（有/没有/仅剩哪些席别），再给明细
- 时刻表按站序列表，首末站标注始发/终到
- 数据来自 12306 实时接口，**如实转述，禁止编造车次、时刻或余票数量**；接口失败时如实报错并建议重试
- 用户表达购票意向时，主动说明：本 skill 只能查询，购票请用 12306 官方 App/网站（可提醒候补功能）

## 技术备忘（排查用）

- 查询接口要求先请求 `/otn/leftTicket/init` 拿会话 Cookie（`lib12306.new_session()` 已封装）
- 余票端点会不定期迁移（query → queryA → queryG…），返回 JSON 的 `c_url` 字段会告知新端点，库会自动跟随；全部失败时报错提示
- 车站代码表缓存于系统临时目录（7 天有效期）
- 频率敏感：短时间高频请求会被风控，避免循环批量查询
